# Equilibrium Lost - Runtime Art Spec

## Runtime Target

- **Canvas:** 1920 x 1080.
- **Rendering:** non-pixel-art. `gameConfig.pixelArt` is `false`; PNGs are antialiased and designed for smooth scaling.
- **Source of truth:** `src/content/data/assetManifest.json`.
- **Runtime paths:** every `images` entry maps a logical Phaser texture key to `public/assets/images/<key>.png`.
- **Generated output:** committed PNGs. The build and game runtime do not call the generator.

## Generator

Art is generated by `scripts/gen-assets.mjs` using SVG templates rendered to PNG with the dev-only dependency `sharp`.

Regenerate all PNGs:

```sh
node scripts/gen-assets.mjs
```

The script iterates over `assetManifest.images`, looks up each key's target size in `assetManifest.placeholders`, and writes the PNG to the manifest path. New keys are picked up automatically as long as the manifest has both an `images` entry and a matching placeholder size.

For a future region, add:

- `tiles_<region>` and `bg_battle_<region>` entries to the manifest.
- Enemy and NPC sprite keys in the manifest as content references them.
- One optional palette entry in `REGIONS` inside `scripts/gen-assets.mjs`.
- Optional enemy/NPC style mappings in `ENEMIES` and `NPCS` for stronger silhouettes.

If no explicit mapping exists, the generator uses a generic chemistry motif in the manifest color.

## Visual Style

- Clean, modern cel-shaded shapes with dark outlines.
- Simple chemistry motifs: atom orbitals, ion clouds, molecular bonds, lattice grids, flames, beakers, precipitation crystals, and reaction sparks.
- Transparent backgrounds for sprites and icons that are placed over game scenes.
- Full-canvas opaque art for `title_art`, `worldmap`, and `bg_battle_*`.
- No baked-in labels on character, NPC, enemy, UI, or status sprites. Title and world-map art may include their own title/map lettering.

## Palettes

- **The Elemental Reaches:** cosmic teal and blue-green, with pale orbital highlights and warm path tones.
- **The Bonding Forge:** iron-grey, dark furnace brown, copper, and ember-orange.
- **Reaction Hollow:** dark volcanic browns with amber, sulfur-yellow, and combustion-orange accents.
- **Shared UI:** dark navy panels, thin blue or amber accent borders, low-noise interiors so stretched panels remain readable.

## Sizes And Naming

All sizes come from `assetManifest.placeholders`. Current conventions:

- `title_art`: 1920 x 800.
- `worldmap`: 1920 x 1280.
- `bg_battle_<region>`: 1920 x 896.
- `tiles_<region>`: 64 x 64 representative textured tile.
- `hero_<class>_<stage>_overworld`: 64 x 96.
- `hero_<class>_<stage>_battle`: 192 x 192.
- `enemy_<id>`: 96 to 256 square, according to enemy role.
- `npc_<id>`: 64 x 96.
- `ui_textbox` and `ui_chainmeter`: 64 x 64 stretch-friendly panels.
- `icon_status_<id>`: 48 x 48.

## Tilesets

The generated `tiles_*` PNGs are currently single 64 x 64 representative textured tiles. The overworld scene still renders its map procedurally from its biome palette, so these are loaded and available but not yet used as tile atlases.

If tile rendering is upgraded later, keep the fallback path: use `region.tilesetKey` only when the sheet exists, and fall back to the procedural `BIOMES` palette when it does not.

## Loader And Fallback

`BootScene` loads every `assetManifest.images` entry with `this.load.image(key, manifest.images[key])`. After the Phaser loader completes, it calls `generatePlaceholderTextures`.

`generatePlaceholderTextures` skips keys that already have a loaded texture, so only missing or failed PNGs become generated colored rectangles. Placeholder labels are only drawn for generated fallback textures, not for real PNGs.

This means a missing or broken PNG should be visually obvious but safe:

- The game continues booting.
- The affected asset displays its manifest-colored fallback rectangle.
- Other real art remains loaded.
- Content validation warnings from `loadGameContent()` are unchanged by art file presence.
